## How It Works

### 1. Configuration (One-Time Setup)
1. Navigate to `/payments/methods` in SolidInvoice
2. Click on "Bank Transfer" 
3. Fill in the form fields:
   - **Bank Name**: e.g., "Commonwealth Bank"
   - **Account Name**: e.g., "Smith Tree Services"
   - **BSB**: e.g., "123-456"
   - **Account Number**: e.g., "12345678"
   - **Reference Instructions**: e.g., "Please use invoice number as reference"
4. Enable the payment method
5. Save

### 2. Automatic Template Population
- Once configured and enabled, bank details appear on ALL invoices and quotes
- No need to re-enter details for each invoice
- Details persist until manually changed
- Shows in footer section alongside terms

### 3. Template Display Format
```
Bank Transfer Details
Bank Name: Commonwealth Bank
Account Name: Smith Tree Services  
BSB: 123-456
Account Number: 12345678
Please use invoice number as reference
```
