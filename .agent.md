# SolidInvoice Project Context

SolidInvoice is an open-source invoicing application for small businesses and freelancers, built with PHP (Symfony 7.x) and TypeScript/JavaScript (Stimulus, Webpack Encore, Bun). It features robust client, quote, invoice, and payment management, with a RESTful API and multi-channel notifications. The architecture follows Domain-Driven Design with specialized Symfony bundles. It supports MySQL/PostgreSQL and uses FrankenPHP for serving. Recent enhancements include bank transfer integration for service-based businesses.

## Key Technologies for Extension:
- **Backend**: PHP 8.3+, Symfony Framework 7.x, Doctrine ORM, API Platform, Payum.
- **Frontend**: TypeScript/JavaScript, Stimulus, Twig Components, SCSS (Bootstrap 4, AdminLTE).
- **Build Tools**: Webpack Encore, Bun.
- **Database**: MySQL 8.0+ / PostgreSQL 13+.
- **Application Server**: FrankenPHP (Caddy-based).

## Core Business Domains (Symfony Bundles):
- `ClientBundle`: Client/contact management.
- `InvoiceBundle`: Invoice creation, management, recurring invoices.
- `QuoteBundle`: Quote/estimate generation.
- `PaymentBundle`: Payment processing.
- `TaxBundle`: Tax calculation.
- `UserBundle`: User authentication/authorization.

## Recent Enhancements:
- **Bank Transfer Integration**: Automated bank details on invoices/quotes, Australian banking support.

## Development Environment Setup:
- Clone repository.
- `composer install` (PHP dependencies).
- `bun install && bun run dev` (Node packages & asset compilation).
- `php -S localhost:8000 -t public` or `symfony serve` (local server).
