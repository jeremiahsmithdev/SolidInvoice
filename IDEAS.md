✨ Feature Enhancements & Missing Functionality

✅ 1. Job Photos & File Attachments

	•	Support file attachments (e.g. council permits, PDFs)
	•	Preview in browser with optional watermarking

🌳 Why: Enhances documentation and reduces disputes

⸻

✅ 2. Job Checklist / Task Breakdown
	•	Add checklist per job (e.g. “Access”, “Permit secured”, “Ropes ready”)
	•	Predefined templates per job type
	•	Auto-clear when job marked “Complete”

🧠 Why: Encourages standard operating procedures for teams

⸻

✅ 3. “Day View” Dashboard (Job Run Sheet)
	•	Daily agenda-style list of jobs (filter by team or location)
	•	Print/PDF export for field crews
	•	Drag to reorder if needed

📅 Why: Operational visibility and print-friendly backup for offline

⸻

✅ 4. Invoice Follow-up Automations
	•	Automatic reminder if invoice status = “Invoice Sent” > 7 days
	•	Option to trigger email or SMS with friendly nudge
	•	Toggle per invoice

📨 Why: Reduces unpaid jobs and saves admin time

⸻

✅ 5. Quick-Create Buttons (Everywhere)
	•	“+ Quote from Job”
	•	“+ Job from Enquiry”
	•	“+ Invoice from Quote”

⚡ Why: Makes the system feel snappy, intuitive, and productive

⸻

🎨 Design Language Suggestion: “Calm Design”

Inspired by neuroscience + UI research into attention fatigue (see: Calm Technology by Amber Case)

Key principles:
	•	✴️ Minimal Color Palette: Status colors only used where necessary
	•	🕊️ Whitespace & Padding: Generous breathing room
	•	🔕 Reduce Noise: Hide advanced options behind toggles
	•	🧭 Fitts’s Law: Big, accessible buttons for key actions
	•	📱 Mobile-First Touch Targets: Field use = large tap areas

Stack Suggestion: Tailwind CSS + Headless UI (or DaisyUI) to quickly scaffold clean, accessible UIs with minimal effort.
